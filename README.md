## About the Project

The Placement Preparation Portal is a web-based application designed to help students prepare for placement opportunities. It provides a centralized platform for accessing company information and placement-related resources.

## Key Features

- Student registration and login.
- Student dashboard.
- Company information and questions.
- Admin dashboard.
- Placement preparation resources.
- Database-driven web application.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** PHP
- **Database:** MySQL
- **Local Server:** XAMPP
- **Version Control:** Git and GitHub

## Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/pavanmchaudhari06/placement-preparation-portal.git
```

**2. Move the project**

Place the project folder inside:

```text
C:\xampp\htdocs\
```

**3. Start XAMPP**

Start Apache and MySQL.

**4. Configure the database**

- Open `http://localhost/phpmyadmin`.
- Create the database matching the name configured in `includes/db.php`.
- Import the required base database SQL file.
- Apply the company questions upgrade SQL file if required.

**5. Run the project**

Open:

```text
http://localhost/placement-portal/
```
